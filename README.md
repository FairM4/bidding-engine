Bidding Engine
The Bidding Engine contract provides a decentralized auction and bid management system on the Stacks blockchain.
It allows users to create auctions, place competitive bids, and automatically determine winners when auctions end.
The contract ensures transparent, time-bound, and tamper-proof bidding using Clarity smart contracts.

Features
Create and manage live auction sessions
Place STX bids with dynamic highest-bid tracking
Auto-refund non-winning participants
Reserve price and auction deadline enforcement
Transparent on-chain records for all bids
Event logs for bid placement, winner selection, and payouts

Technical Overview
Language: Clarity
Purpose: Enable fair and secure auctions with automatic winner payout
Usable For: NFT sales, token auctions, collectibles, and marketplace systems
